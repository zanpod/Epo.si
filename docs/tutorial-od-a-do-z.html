Od A do Ž: predstavitvena spletna stran za vaš biznis

Korak za korakom, brez predznanja programiranja: od praznega računa do žive spletne strani z urejevalnim admin panelom, bazo podatkov in gostovanjem — vse na brezplačnih paketih treh orodij: GitHub, Supabase in Netlify.

01
GitHub

Pridobite kopijo predloge

  1. Pojdite na repozitorij predloge na GitHubu (povezavo dobite od predavatelja tečaja).
  2. Kliknite zeleni gumb »Use this template« (ali »Fork«) — nastane vaša lastna kopija pod vašim GitHub računom. Če še nimate računa, se brezplačno registrirajte na github.com/signup.
  3. Poimenujte repozitorij (npr. moje-podjetje-splet) in kliknite Create repository.
Rezultat

V svojem GitHub računu imate zdaj svojo kopijo vseh datotek strani: index.html, css/, js/, supabase/ …

02
Supabase

Registracija in nov projekt

  1. Pojdite na supabase.com in kliknite Start your project.
  2. Registrirajte se — najhitreje z GitHub računom (en klik).
  3. Kliknite New project in izpolnite:
    PoljeKaj vnesti
    NameIme vašega podjetja, npr. moje-podjetje
    Database PasswordUstvarite močno geslo in ga shranite (npr. v upravitelja gesel)
    RegionRegija blizu vas, npr. Central EU (Frankfurt)
  4. Kliknite Create new project in počakajte 1–2 minuti.
  5. Ko je projekt pripravljen, pojdite v Project Settings → API. Zabeležite si:
    • Project URL — oblike https://xxxxxxxxxxxx.supabase.co
    • anon public key — dolg niz znakov (npr. začne se z eyJ... ali sb_publishable_...)
Opozorilo

Nikoli ne delite ali objavljajte ključa service_role (drugačen od »anon public«) — ta ima poln dostop do baze. Za to stran ga ne potrebujete.

03
GitHub

Povežite ključe s stranjo

  1. V svojem repozitoriju odprite datoteko js/supabase-config.js (svinčnik za urejanje neposredno na GitHubu, ali repozitorij prenesite na računalnik).
  2. Zamenjajte vrednosti s svojimi:
const SUPABASE_URL = 'https://xxxxxxxxxxxx.supabase.co';
const SUPABASE_ANON_KEY = 'vaš-anon-public-ključ';

Shranite spremembo (na GitHubu: Commit changes).

04
Supabase

Zaženite bazo podatkov

Ta korak pripravi vse »predale« (tabele) za vsebino strani: nastavitve, storitve, projekte, sporočila.

  1. V Supabase pojdite na SQL Editor in kliknite New query.
  2. Odprite datoteko supabase/schema.sql v repozitoriju in skopirajte celotno vsebino.
  3. Prilepite v SQL Editor in kliknite Run (ali Ctrl/Cmd + Enter).
  4. Ob uspehu se v Table Editor pojavijo nove tabele: settings, services, projects, contacts, posts.
Nasvet

To storite samo enkrat, ob prvi postavitvi.

05
Supabase

Ustvarite shrambo za slike

  1. V Supabase pojdite na Storage → New bucket, ime: portfolio, vklopite Public bucket → Save.
  2. Pojdite na Storage → Policies (za bucket portfolio) in dodajte tri pravila:
Ime pravilaOperacijaPogoj
Public can view imagesSELECTtrue
Auth can upload imagesINSERTauth.role() = 'authenticated'
Auth can delete imagesDELETEauth.role() = 'authenticated'
Bližnjica

Namesto ročnega dodajanja lahko v schema.sql odkomentirate razdelek s »storage policy« in ga poženete v SQL Editorju — naredi isto stvar samodejno.

06
Supabase

Ustvarite admin uporabnika

  1. V Supabase pojdite na Authentication → Users.
  2. Kliknite Add user → Create new user.
  3. Vnesite svoj e-poštni naslov in močno geslo.

To sta podatka, s katerima se boste prijavili na /admin strani vaše spletne strani.

07
Netlify

Registracija in objava v živo

  1. Pojdite na netlify.com in se registrirajte — najhitreje z GitHub računom.
  2. Kliknite Add new site → Import an existing project.
  3. Izberite GitHub in poiščite svoj repozitorij (npr. moje-podjetje-splet).
  4. Nastavitve gradnje pustite prazne (ni build ukaza, publish directory = /).
  5. Kliknite Deploy site.
Rezultat

Po ~30 sekundah je stran objavljena na naslovu tipa https://naključno-ime-1234.netlify.app — to je vaša prava, delujoča spletna stran. Vsakič, ko kasneje spremenite kodo v repozitoriju, jo Netlify samodejno znova objavi v minuti ali dveh.

08
Netlify + Supabase

Prva prijava in urejanje vsebine

  1. Odprite https://vaša-stran.netlify.app/admin.
  2. Prijavite se z e-pošto/geslom iz koraka 06.
  3. V levem meniju admin panela uredite:
RazdelekKaj urejate
HeroGlavni naslov, podnaslov, gumbi za akcijo (CTA)
O meniFotografija, opis, veščine, statistika
StoritveDodajte/uredite/izbrišite kartice storitev
ProjektiNaložite slike, dodajte/uredite/izbrišite reference
SporočilaVsa sporočila, poslana preko kontaktnega obrazca
ObjavePriprava vsebin za Instagram/Facebook (neobvezno)
NastavitveIme strani, kontakt, povezave do omrežij, SEO

Vsaka sprememba se shrani takoj po kliku na Shrani — osvežite javno stran, da vidite rezultat.

09
Netlify

Lastna domena

Če imate ali kupite domeno (npr. vasepodjetje.si) pri registratorju (Arnes, WebHostFace, GoDaddy, Namecheap …):

  1. V Netlify pojdite na Site settings → Domain management → Add a domain.
  2. Vnesite svojo domeno.
  3. Netlify pokaže DNS nastavitve (nameserverje ali A/CNAME zapise) — vnesete jih pri svojem registratorju domene.
  4. Počakajte 10 minut do 24 ur, da se DNS razširi. Netlify samodejno priskrbi tudi brezplačno HTTPS potrdilo.
Medtem

Do takrat lahko stran mirno uporabljate na začasnem netlify.app naslovu.

10
Neobvezno

Dodatne funkcije

Naslednje funkcije niso potrebne za osnovno delovanje strani — dodate jih lahko kasneje, ko se z osnovami spoznate.

E-poštna obvestila o sporočilih (Resend)

Ko obiskovalec odda kontaktni obrazec, lahko dobite e-poštno obvestilo.

  1. Namestite Supabase CLI na svoj računalnik.
  2. V terminalu, znotraj mape projekta:
supabase login
supabase link --project-ref VAŠ-PROJECT-REF
supabase functions deploy send-contact-email

V Supabase → Edge Functions → send-contact-email → Secrets dodajte:

KljučVrednost
RESEND_API_KEYAPI ključ iz resend.com
NOTIFY_EMAILE-naslov za prejemanje obvestil
FROM_EMAILPotrjen pošiljateljski naslov na Resend

Sporočila se v bazo shranijo tudi brez tega koraka — e-poštna obvestila so le dodatna udobnost.

AI klepet za obiskovalce (Groq)

Plavajoče klepetalno okno, ki odgovarja samo na vprašanja o vaših storitvah in ceniku.

  1. Ustvarite brezplačen ključ na console.groq.com/keys.
  2. supabase functions deploy chat
  3. V Edge Functions → chat → Secrets dodajte GROQ_API_KEY.
  4. Besedilo/pravila klepeta uredite v supabase/functions/chat/index.ts (SYSTEM_PROMPT).

Generator objav za družbena omrežja (Groq)

Admin razdelek Objave pripravi objave (hook, opis, hashtagi) ali 7-dnevni načrt vsebin.

  1. supabase functions deploy generate
  2. V Edge Functions → generate → Secrets dodajte GROQ_API_KEY (lahko isti kot zgoraj).

Pošiljanje slik direktno v Canvo

  1. Na canva.com/developers ustvarite integracijo, omogočite scope-e asset:write, design:content:write, design:meta:read, dodajte redirect URL svojega admin naslova (npr. https://vasa-stran.si/admin/).
  2. supabase functions deploy canva
  3. V Edge Functions → canva → Secrets dodajte CANVA_CLIENT_ID in CANVA_CLIENT_SECRET.
  4. Ob prvem kliku na »Pošlji v Canvo« se enkrat prijavite — nato se povezava zapomni.
11
Vsebina

Piškotki in zasebnost (GDPR)

Predloga že vsebuje pasico za soglasje ob prvem obisku, ki uporablja samo nujno potreben localStorage (ne pravega sledilnega piškotka), in stran Zasebnost (zasebnost.html).

Preden objavite

Dopolnite zasebnost.html s svojimi resničnimi podatki: naziv podjetja, matična številka, kontaktni e-naslov.

12
Varnost

Varnostni nasveti

  • Mapa admin/ ni zaščitena na nivoju datotek — dostop nadzoruje Supabase Auth v brskalniku.
  • Vse operacije pisanja v bazo zahtevajo prijavljenega uporabnika (t. i. RLS politike, že pripravljene v schema.sql).
  • Za dodatno zaščito lahko na Netlify z datoteko _redirects zaščitite pot /admin/* še na nivoju CDN.
  • Uporabite močno, edinstveno geslo za svoj admin račun.
Nikoli

Ne objavite ali delite ključa service_role — v tem projektu ga sploh ne potrebujete.

14
Po zagonu

Redno vzdrževanje

  • Vsebino (besedila, cene, projekte) urejate sproti v admin panelu — brez spreminjanja kode.
  • Sporočila strank redno preverjajte v razdelku Sporočila.
  • Nova koda na GitHubu se samodejno objavi na Netlify — ni ročnega koraka.
  • Gesli za Supabase in Netlify shranite v upravitelja gesel in omogočite dvostopenjsko preverjanje, če je na voljo.

Slovarček od A do Ž

Admin panel
Zaščiten del strani (/admin), kjer urejate vsebino brez pisanja kode.
API ključ
»Geslo«, s katerim se stran predstavi Supabase bazi (javni anon ključ je varen za brskalnik).
Bucket (Storage)
Prostor za shranjevanje datotek (slik) v Supabase.
CDN
Mreža strežnikov, ki stran prikaže obiskovalcem hitro, ne glede na to, od kod prihajajo.
Deploy (objava)
Postopek, ko Netlify vzame kodo in jo objavi na spletu.
DNS
Sistem, ki ime domene poveže s pravim strežnikom.
Domena
Spletni naslov podjetja, npr. vasepodjetje.si.
Edge Function
Majhen program na strežniku Supabase (pošiljanje e-pošte, klic AI-ja) — občutljivi ključi ostanejo skriti.
GitHub
Storitev za shranjevanje in različičenje kode; repozitorij je mapa s kodo in zgodovino sprememb.
Hosting
Strežnik, kjer »živi« spletna stran (v tem primeru Netlify).
HTTPS
Šifrirana povezava (ključavnica v brskalniku) — Netlify jo priskrbi samodejno.
Repozitorij
Mapa s kodo strani, shranjena na GitHubu.
RLS
Pravila v bazi, ki določajo, kdo lahko bere/piše posamezne podatke.
Schema (schema.sql)
Datoteka, ki v bazi ustvari vse potrebne tabele.
Supabase
Storitev za bazo podatkov, prijavo uporabnikov in shrambo datotek.
Tabela
»Predal« v bazi podatkov, npr. tabela services hrani storitve.
